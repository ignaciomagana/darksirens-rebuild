## Purpose

L8 is a freeze/acceptance slice. It adds no new lensing physics. Its job is to
close the reconstructed lensing companion with one full fixed-theta oracle that
crosses the previously accepted layers in a single calculation:

```text
singleton PE rows
+ candidate-edge J=2 pair PE rows
+ ordinary and lensed selection
+ finite-sample correction
+ exact compatible graph matchings
+ matching-prior normalization
+ exact partition marginalization.
```

The production implementation being accepted is the L7 composition surface;
L8 adds the frozen reference, parity test, and final documentation only.

## Frozen scientific contracts

The completed Phase-11 stack freezes the following behavior:

1. Weak-lensing PDF/quadrature and spectral-siren integration are owned by the
   lensing companion, with the ordinary population/cosmology implementation
   still owned by core.
2. SIS strong-lensing and Finn-Chernoff detection conventions are explicit and
   tested.
3. J=2 pair evidence uses the accepted symmetric, unmarked L4 pair surface.
4. The exactly-one-detected singleton channel and J=2 channel are views of one
   source-draw campaign; shared-campaign selection covariance is retained.
5. The lensed selection denominator is the total number of source draws, not
   the retained count.
6. Mature lensed detection membership is pre-rendered at the campaign
   cosmology. Variable-cosmology use therefore fails closed rather than
   silently reusing inconsistent detection flags.
7. Candidate-pair uncertainty is an exact graph-matching partition problem;
   edge prior/allowed mark contributions are applied once.
8. All event/edge terms are evaluated once per parameter point and reused
   algebraically across exact matchings.
9. Partition priors are explicitly normalized:

   `log L = logsumexp_P(log L_P + log pi_P) - logsumexp_P(log pi_P)`.
10. Time-marked candidate edges fail closed until a marked pair-likelihood
    surface is deliberately implemented; L8 does not pretend the unmarked L4
    surface consumes arrival-time information.
11. Lens-only rate coordinates remain outside the core parameter namespace.
