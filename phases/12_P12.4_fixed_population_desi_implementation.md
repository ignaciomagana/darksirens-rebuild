## Composition architecture

The consumer does not reproduce a private DESI likelihood. It composes accepted package seams:

```text
ang2pix_ring
compact_pe_selection_catalog
selection_completion_curves
build_incomplete_catalog_prior_state_from_curves
host_density_log_likelihood
InferenceTarget / combine_parameter_plans
```

For each proposed `(H0, M0hat, sigma_M)` point, the DESI magnitude-selection completion curves and ordinary incomplete-catalog prior state are constructed once before the blocked PE/injection reducers are entered. The full catalog state is therefore not rebuilt independently inside every PE event block or selection batch.

This was the reason for the narrow Phase 12A core seam; no new completeness equation exists in the consumer repository.

## Fail-closed execution order

`scripts/run_fixed_population_desi.py` refuses to sample unless all of the following are true:

1. P12.1 bootstrap JSON has schema/status PASS and resolves the exact current four-package manifest;
2. the current interpreter independently re-verifies those same package SHAs through PEP-610 provenance;
3. P12.2 is accepted for the exact 259-event primary sample;
4. P12.3 is accepted for the same sample and records the same current package commits;
5. the primary PE, injection and standardized DESI catalog files exist;
6. the P12.4 anchor point passes the hard Monte-Carlo reliability criteria;
7. the posterior-center diagnostic also passes after TinyNS.

The hard reliability conditions remain

```text
sum_i sigma_i^2 + N_obs^2 / N_eff <= 1
N_eff > 5 N_obs
finite hard selection correction
```

No soft selection-Neff guard is permitted for the production P12.4 acceptance run.
